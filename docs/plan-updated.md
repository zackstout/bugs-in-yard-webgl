## New requirements

All irrelevant creatures should be hidden when a layer is selected. If Diptera is the current level, all non-Diptera arthropods and creatures should be hidden. If the family Miridae is the current level, all non-Miridae creatures should be hidden. This includes all other members of the order Hemiptera.

We should extend the "single representative" idea to all possible zoom levels. That is, if a user selects a family that has multiple sub-families, or genuses, within it, each of those should be given a single representative as well.
